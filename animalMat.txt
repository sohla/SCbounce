OVERVIEW
--------
The animalMat.sc file is a SuperCollider personality module that evolved from a
multi-sample playback system into a sophisticated gesture-controlled granular
sampler. This file represents one performer's sonic identity in what appears to be
a music-motion interactive performance system.


PHASE 1: INITIAL DEVELOPMENT (July 2024)
-----------------------------------------
Commits: ea1fe13 (Jul 15) - 3ef6922 (Jul 15)

Initial Configuration:
- Used multiple voice recordings from a workshop (2July2025/converted folder)
- Employed ~buffersB array loading 16+ sample files
- Simple stereo sampler with basic ADSR envelope
- Pattern used fixed buffer index (~buffersB[15])
- Musical parameters:
  * Rate variations: [0,2,-2].midiratio then simplified to [0,-0].midiratio
  * Start positions: Randomized through 8 different points in sample
  * Note: Changed from 32 to 33

Key Characteristics:
- Bulk buffer loading approach
- Static sample selection
- Commented-out MIDI channel assignment (m.midiChannel = 1)
- Included unused callback functions (~onEvent, ~onHit, ~stop, ~nextMidiOut)


PHASE 2: MAJOR REFACTOR (August 2024)
--------------------------------------
Commits: 958152 (Aug 25) - 307ce1a (Aug 25)

This represents a fundamental architectural shift:

Sample Management:
- REMOVED: Bulk folder loading (~sampleFolderB, ~buffersB array)
- ADDED: Single-file loading system (yourDNASamples/STE-1004.wav)
- Implemented proper buffer lifecycle management with callbacks
- Added buffer allocation/deallocation logging

Audio Engine Changes:
- Maintained \stereoSampler SynthDef
- Changed from static to computed rate patterns: [0,12,-5,7].stutter(8).midiratio
- Quantization tightened: 0.25 → 0.04

Gesture Mapping Introduction:
- Added gyroscope control for octave: gyroEvent.y mapped to 2-6 octave range
- Acceleration mass mapping refined with threshold logic
- Duration control: accelMassFiltered → 0.8 to 0.04 range with lag(2)
- Binary amplitude switching: if(amp < 0.06) then 0 else 3

Configuration Parameters:
- Added m.rrateMassFilteredAttack = 0.8
- Added m.rrateMassFilteredDecay = 0.2

Code Cleanup:
- Removed all commented-out legacy code
- Removed unused functions (~onEvent, ~onHit, ~stop, ~nextMidiOut)
- Simplified ~deinit to use composition operator (<>)
- Changed plot to show gyro data instead of rrate data


PHASE 3: SOUND DESIGN EVOLUTION (August-November 2024)
-------------------------------------------------------
Commits: Various tweaks and refinements

SynthDef Enhancement (\stereoSamplerAM):
- Renamed from \stereoSampler to \stereoSamplerAM
- Added timeScale parameter (ts) for envelope stretching
- Refined filter: Changed RQ from 1.0 → 0.3 (narrower bandwidth)
- Changed stereo balancing: Balance2.ar → Pan2.ar with pan.lag(2)
- Modified output: Now outputs only left channel (sig[0])

Musical Parameter Evolution:
- Rate changed: From melodic intervals to continuous Pwhite(1.3,1.6)
- Duration curve refined: Multiple lincurve experiments (-3, -1 curve values)
- Legato parameter introduced: Linked to accelMassFiltered
- Start positions: Changed from Pseq to fixed pattern cycling

Gesture Mapping Sophistication:
- Cutoff frequency: gyroEvent.y → exponential 5540-14000 Hz range
- Pan control: gyroEvent.z → -1 to 1 stereo field
- TimeScale (legato): accelMassFiltered → 0.6 to 0.2

Filter Parameter Tuning:
- Attack/Decay balance: 0.8/0.2 → 0.8/0.7 (slower decay)


PHASE 4: PERFORMANCE INTEGRATION (November 2025)
-------------------------------------------------
Commits: 6c80e3d (May 8) - a05488c (Nov 30)

Major Control Logic Addition:
- Digital input control for play/pause (d.sensors.digiInEvent[0])
- Automatic pattern resume/pause based on digital trigger
- Enables foot pedal or button-based performance control

Amplitude Source Change:
- CRITICAL SHIFT: Amplitude now driven by gyroYFiltered instead of accelMass
- New mapping: gyroYFiltered.lincurve(-1.0, 1.0, 0.5, 1, -2)
- Duration also linked to gyroYFiltered: 0.5 to 0.075 range
- Removed binary amplitude thresholding

Parameter Adjustments:
- Final amplitude multiplier: amp*1 (previously varied 0.8-1.1)
- Duration lag removed from final version (was 0.2)
- Commented out multiple experimental duration calculations
